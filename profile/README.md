## Host your apps, bots and databases in seconds

**Vertra Cloud** is a Brazilian cloud platform for developers. Upload your project or connect a repository and we build, run and publish it for you: bots, APIs, websites and databases, with live logs, metrics, snapshots and team workspaces.

- **Deploy in one step:** from the dashboard, the CLI, a GitHub Action, VS Code or the API.
- **Managed databases:** create, connect and back up without touching a server.
- **Built for teams:** workspaces with roles and permissions.
- **AI-ready:** an official MCP server lets your AI agent manage your projects.

## Get started

```bash
curl -fsSL https://cli.vertracloud.app/install | sh
vertra auth login
```

Read the [quick start guide](https://docs.vertracloud.app) to deploy your first app.

## Official tools

| Project | Description |
|---|---|
| [cli](https://github.com/vertracloud/cli) | Deploy and manage everything from your terminal |
| [vscode-extension](https://github.com/vertracloud/vscode-extension) | Manage your apps without leaving the editor |
| [github-action](https://github.com/vertracloud/github-action) | Deploy on every push with GitHub Actions |
| [mcp](https://github.com/vertracloud/mcp) | MCP server for AI agents (`npx -y @vertracloud/mcp`) |
| [sdk-api-js](https://github.com/vertracloud/sdk-api-js) | JavaScript/TypeScript SDK (`npm i @vertracloud/sdk-api`) |
| [sdk-api-py](https://github.com/vertracloud/sdk-api-py) | Python SDK (`pip install vertracloud-api`) |
| [sdk-api-go](https://github.com/vertracloud/sdk-api-go) | Go SDK (`go get github.com/vertracloud/sdk-api-go`) |
| [api-types](https://github.com/vertracloud/api-types) | Public API types (`@vertracloud/api-types`) |
| [docs](https://github.com/vertracloud/docs) | Documentation source, contributions welcome |
